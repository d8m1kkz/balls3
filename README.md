# Шарики

Интерактивная симуляция в браузере: три цвета шариков взаимодействуют друг с другом по своим правилам, и из простых законов получается сложное поведение: скопления, «пузыри», вспышки и лопающиеся шарики.

Каждый запуск с новым набором правил даёт свою картину. Правила задаются коэффициентами: один цвет может притягивать или отталкивать другой, а между одинаковыми шариками действует отталкивание.

## Что внутри

- **Красные, зелёные и синие шарики** рождаются из пустоты, сталкиваются, отскакивают, иногда сливаются в новый шарик или лопаются.
- **9 готовых наборов правил** — переключаются кнопками внизу слева или клавишами `1`–`9`.
- **Панель с коэффициентами** показывает, как каждый цвет реагирует на другие, сколько шариков каждого цвета сейчас на экране и насколько плотно они собрались.
- Мир подстраивается под размер окна.

## Запуск

Самый простой способ — открыть файл `Public/index.html` в браузере.

Или через Docker (нужен [Docker Compose](https://docs.docker.com/compose/)):

```bash
docker compose up
```

После этого откройте в браузере http://localhost:8080. Другой порт можно задать переменной `PORT`, например `PORT=3000 docker compose up`.

## Структура проекта

```
Public/
  index.html   — страница
  script.js    — физика, рисование и управление
  style.css    — оформление и панель управления
compose.yaml   — запуск через nginx в Docker
```

Проект не требует сборки и внешних зависимостей: это обычные HTML, CSS и JavaScript.
